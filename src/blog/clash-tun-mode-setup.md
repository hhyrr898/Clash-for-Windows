Clash for Windows 0.20.39 在 Windows 11 23H2 上开启 TUN 模式，因依赖虚拟网卡与系统服务，首次配置常遇阻碍，而该版本正是 2023 年 11 月项目停更后的最终版，实操细节仍具参考价值。

本文解决首次开启 TUN 模式的配置报错与无法接管问题，看完你能按流程成功启用 TUN，让命令行工具、游戏及 UWP 等应用被全局接管，省去逐个配代理的麻烦，并明确该桌面端已无官方手机版。

## 准备工作：先确认三件事

开始前我先确认了三点，能省掉后面一大半的麻烦。

第一，客户端必须是完整安装版，不是绿色版解压即用。TUN 要注册系统服务、装虚拟网卡驱动，绿色版经常缺权限。如果你还没装，可以先看[安装步骤](/blog/clash-for-windows-install-guide/)，注意安装路径别带中文和空格。

第二，配置文件得先能正常用。TUN 只是流量入口，订阅本身有问题的话，开了 TUN 只会更乱。订阅导入的细节我在[这篇订阅导入教程](/blog/clash-subscription-import-tutorial/)里写过，建议先确认节点能连通再折腾 TUN。

第三，把系统里其他 VPN、加速器、虚拟机网络先关掉。我第二次失败就是因为 VMware 的虚拟网卡和 TUN 抢路由表。

## 开启 TUN 的具体步骤

下面是我实际操作的顺序，四步走完基本就能通。

1. **以管理员身份启动 Clash for Windows。** 右键快捷方式选"以管理员身份运行"，这一步不能省。非管理员启动时，Service Mode 那一栏会是灰色，点了也没反应。

2. **安装 Service Mode。** 打开主界面左侧的 General，找到 Service Mode，点 Manage，在弹出的窗口里点 Install。等进度条走完，状态变成绿色的 Running 才算成功。这一步本质是注册一个后台服务，后面虚拟网卡的创建和路由改写都靠它。

3. **安装 TUN 虚拟网卡。** 还是在 General 页，找到 TUN Mode，先把开关打开，此时会提示需要安装 Wintun 驱动，点确认。驱动装完后，在系统的"网络连接"里应该能看到一块名为 `wintun` 或 `Clash` 的虚拟网卡，状态是已连接。

4. **验证流量是否真的走了 TUN。** 我习惯用两种方式交叉验证：一是打开命令提示符跑 `curl -v https://www.google.com`，看返回是否正常；二是在 Clash 的 Connections 面板里看有没有实时连接记录。如果 curl 通了但面板没记录，多半是流量没进 TUN，回去检查上一步的网卡状态。

补充一句，TUN 开启后建议把系统代理关掉，两者同时开容易出现回环。切换节点的逻辑和系统代理一样，配置文件的写法可以参考[YAML 基础说明](/blog/clash-config-yaml-basics/)，TUN 本身不改变配置结构。

## 我踩过的几个坑

第一次开 TUN 时，我卡在 Service Mode 一直装不上，点了 Install 转两圈就变回 Stopped。后来发现是杀毒软件把服务安装拦了，加白名单后重装才过。

第二次是网卡装好了但没网。排查下来是 DNS 没走 TUN，浏览器还在用运营商的 DNS，解析出来的地址直接绕过了代理。在配置里显式指定 `dns.enable: true` 并配好 `nameserver` 后恢复正常。这类问题定位起来比较费劲，我后来整理了一套[网络连通性排查方法](/blog/clash-for-windows-network-check/)，按顺序查 DNS、路由表、防火墙，比瞎试快得多。

还有一次是日志里反复刷 `TUN adapter not found`，重装驱动也没用，最后发现是 Windows 更新后网卡被禁用，去设备管理器里重新启用就好了。所以遇到怪问题，先看日志，[日志阅读的方法](/blog/clash-for-windows-log-reading/)能帮你少走弯路。

## 常见问题

**Q1：TUN 模式开了，但浏览器还是上不了网，系统代理却正常？**

先看虚拟网卡是否存在且已启用，再看 Clash 日志里有没有 TUN 相关报错。常见原因是路由表没写进去，管理员权限启动后重开一次 TUN 开关通常能解决。另外确认没有同时开系统代理。

**Q2：Service Mode 显示 Running，但 TUN 开关打不开或自动回弹？**

大概率是 Wintun 驱动没装上。去设备管理器看有没有带感叹号的未知设备，有的话卸载重装驱动；也可以先卸载 Service Mode 再重新 Install，顺序别反。

**Q3：开了 TUN 之后局域网设备访问不了，打印机也连不上？**

TUN 会接管默认路由，局域网网段可能被一起劫持。在配置里用 `tun.bypass` 或路由规则把内网段（比如 192.168.0.0/16）排除掉即可。

**Q4：能不能在手机上用同样的 TUN 方案？**

不能。Clash for Windows 没有官方手机版，已于 2023 年停止更新，最后版本 0.20.39。手机上要用 Clash 内核，得换其他客户端，具体可以看[安卓端说明](/blog/clash-for-windows-android-guide/)，思路类似但操作界面完全不同。

TUN 模式配置好之后确实一劳永逸，代价是前期折腾。建议每次改完配置都重启一次客户端，让服务和路由表重新加载，比热切换稳。
